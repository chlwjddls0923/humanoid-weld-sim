# v2 결과 검증 (2026-10-28)

기준: v2 결과(`results/`), seed 2026. 새 결과는 모두 이 폴더(`results_validation/`)에 있고, `results/`·`results_rot0/`·`results_v1_translation_only/`의 CSV는 수정하지 않았다.
재현: `python run_validation.py` (실험 전체 + 표), `python validate_top.py` (모델 타당성). 전체 표는 `tables.md`에 있다.

## 논문에 쓸 숫자

1. **현재 기술(H1, 출발 전 터치 보정)의 흔들림 한계**는 회전 비율 가정에 따라 허용 1.0 mm 기준 **0.1~0.6 mm**, 허용 1.5 mm 기준 **0.2~0.9 mm**다. 실기 수준 흔들림(1.5 mm)에서는 회전 비율·주파수·seed를 바꿔도 허용 1.0 mm 성공률이 모두 **0%**다. 이 결론은 가정에 흔들리지 않는다.
2. **실기 수준 흔들림(1.5 mm)에서 허용 1.5 mm를 95% 이상 지키려면 실시간 보상(H2)의 추정 지연이 15 ms 이하**여야 한다(15 ms에서 97.3%, 10 ms에서 99.7%, 20 ms에서 90.7%). 단, 회전 비율 ℳ(0.0089 rad/mm)와 주파수 0.3~2 Hz를 가정한 값이다.
3. **허용 1.0 mm는 지연만 줄여서는 안정적으로 지킬 수 없다.** 지연 0 ms에서도 흔들림 1.5 mm 성공률이 95.3%(95% CI 92.3~97.2)이고, 흔들림이 없어도 97%다. 한계를 정하는 것은 지연이 아니라 몸통 상태 추정 잡음(0.1 mm / 0.3 mrad 가정)이다.
4. **모델 타당성:** TOP Table IV ℳ의 몸통 오차(병진 1.654/0.461/0.123 mm, 회전 0.0091/0.0114/0.0045 rad)를 G1 골반에 넣으면 토치 끝이 4.7~6.5 mm 움직인다(용접선 끝~시작, 부호 모두 +). 같은 표의 손끝 오차는 5.55 mm(평균 성분의 크기)다. 병진만 넣으면 1.72 mm에 그친다.
5. **통계:** seed 2027로 다시 돌려도 H1 한계(0.5/1.0/1.5 mm 허용에서 0/0.1/0.2 mm)는 같고, H2 성공률은 모두 95% 신뢰구간 안에서 겹친다.

## ⚠ 가정값이 결론을 바꾸는 경우

| 가정 | 바뀌는 결론 | 근거 |
|---|---|---|
| **흔들림 주파수** (논문에 정보 없음) | H2의 성공률과 지연 요구값. H1 결론은 바뀌지 않음 | 지연 20 ms, 흔들림 2 mm, 허용 1.5 mm에서 H2 성공률이 저주파 0.3~0.8 Hz 99.3%, 기본 70.7%, 고주파 1~2 Hz 39.7%. 저주파면 "20 ms로 충분", 고주파면 "20 ms로 크게 부족"이 된다. 지연 × 주파수 조합은 돌리지 않았으므로 **"15 ms 이하" 요구값은 기본 대역(0.3~2 Hz)에서만 성립**한다. |
| **회전 비율** (ℳ 한 점에서 가져옴) | H2(20 ms)가 충분한지 | 흔들림 1.5 mm, 허용 1.5 mm에서 H2 성공률이 비율 0~0.003이면 100%, 0.0089(ℳ)이면 90.7%. 큰 동작 세트 𝒯 비율(0.0007)이면 지연 20 ms로도 충분하다. |
| **추정 잡음** (0.1 mm / 0.3 mrad, 2 Hz 저역통과) | 허용 1.0 mm 이하에서 H2가 가능한지 | 흔들림 0 mm, 지연 0 ms에서도 허용 1.0 mm 97%, 허용 0.5 mm 1.3%. 잡음 가정이 이 상한을 직접 정한다(잡음 크기는 바꿔 보지 않음). |

H1이 실기 수준 흔들림에서 실패한다는 결론은 위 세 가정 모두에서 유지된다.

- **흔들림 1.5 mm, 허용 1.0 mm:** 0~2 ms의 94.3~95.3%는 신뢰구간이 모두 95%를 걸치므로 서로 구별되지 않는다. 지연으로 경계를 정할 수 없고, 추정 잡음이 상한을 정한다.
- **v2와 비교:** 20 ms 행은 v2 `results/`의 H2 값과 같다(97.0 / 90.7 / 67.0 / 6.0 / 0 %). v2가 말한 "지연 20 ms가 회전 성분에서 증폭된다"는 해석과도 맞는다. 지연을 15 ms 이하로 줄이면 실기 수준에서 허용 1.5 mm가 가능해진다는 점은 새로 알게 된 것이다.

## 2. 회전 비율 민감도

**바꾼 것:** `--rot-ratio` 0, 0.0007(TOP 𝒯), 0.003, 0.0089(TOP ℳ = v2 기본값 0.008868). 회전 축 배분은 네 경우 모두 ℳ 비율(0.0091:0.0114:0.0045)을 쓴다. H1 한계는 0~1 mm를 0.1 mm 간격으로 200회, H1·H2 본 실험은 0/0.5/1/1.5/2/3/5 mm × 300회, H2 지연 20 ms.

| 회전 비율 (rad/mm) | H1 한계 허용 1.0 | H1 한계 허용 1.5 | H1 @1.5 mm 허용 1.0 / 1.5 | H2 @1.5 mm 허용 1.0 / 1.5 | H2 한계 허용 1.0 / 1.5 |
|---|---|---|---|---|---|
| 0 (병진만) | 0.6 mm | 0.9 mm | 0 / 30.0 % | 93.0 / 100 % | 1 / 3 mm |
| 0.0007 (𝒯) | 0.5 mm | 0.9 mm | 0 / 25.3 % | 92.0 / 100 % | 1 / 3 mm |
| 0.003 | 0.4 mm | 0.6 mm | 0 / 0 % | 83.7 / 100 % | 0.5 / 3 mm |
| 0.0089 (ℳ, v2) | 0.1 mm | 0.2 mm | 0 / 0 % | 24.0 / 90.7 % | 0 / 1 mm |

- H2 한계는 0/0.5/1/1.5/2/3/5 mm 단계에서 구한 값이다.
- **결론:** H1이 실기 수준에서 실패한다는 결론은 v2와 같다. 다만 H1 한계는 회전 비율에 따라 0.1~0.6 mm로 6배 차이가 난다. 따라서 논문에는 "0.1 mm" 한 값보다 이 범위를 쓰는 편이 맞다. H2(20 ms)가 부족하다는 결론은 ℳ 비율에서만 성립한다.

## 3. 흔들림 주파수 민감도

**바꾼 것:** `--sway-freq` 저주파 0.3~0.8 Hz, 기본 0.3~2.0 Hz, 고주파 1.0~2.0 Hz. H1·H2(20 ms) × 흔들림 0.5/1/2 mm × 300회. "H1 한계"를 구하려고 요청에 없던 H1 세분 실험(0~1 mm, 0.1 mm 간격, 200회)을 추가했다.

| 주파수 대역 | H1 한계 허용 1.0 / 1.5 | H1 최대 이탈 평균 @1 mm | H2 허용 1.0: 0.5 / 1 / 2 mm | H2 허용 1.5: 0.5 / 1 / 2 mm |
|---|---|---|---|---|
| 0.3–0.8 Hz | 0.1 / 0.2 mm | 3.81 mm | 97.0 / 92.0 / 68.7 % | 100 / 100 / 99.3 % |
| 0.3–2.0 Hz (v2) | 0.1 / 0.2 mm | 3.97 mm | 90.7 / 67.0 / 6.0 % | 99.7 / 98.7 / 70.7 % |
| 1.0–2.0 Hz | 0.1 / 0.2 mm | 3.96 mm | 88.7 / 50.7 / 0.3 % | 100 / 96.3 / 39.7 % |

- **H1:** 주파수와 무관하다(한계와 최대 이탈이 같다). 출발 전 보정은 흔들림의 크기만 보기 때문이다. **결론이 v2와 같다.**
- **H2:** 주파수에 크게 좌우된다. 지연 오차가 흔들림 속도(진폭 × 주파수)에 비례하기 때문이다. **결론이 v2와 다를 수 있다.** 위의 "가정값이 결론을 바꾸는 경우" 표를 볼 것. 실제 휴머노이드의 몸통 흔들림 주파수를 측정하거나 인용할 자료가 필요하다.
